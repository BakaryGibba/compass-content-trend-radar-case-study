# Challenges

## External Source Reliability

Google Trends and TikTok-style sources can fail because of rate limits, changed page structures, provider downtime, or geography-specific availability.

Compass addresses this by recording source status and keeping the workflow operational with partial evidence.

## Quality Over Quantity

Trend systems can easily generate too many ideas. Compass counters this with scoring dimensions such as client relevance, buyer intent, content potential, demand, and brand fit.

## AI Trust

AI-generated recommendations need boundaries. The system uses client profiles, risk boundaries, scoring explanations, approval workflows, and fallback behavior so outputs remain reviewable.

## Workflow Complexity

The product spans research, strategy, approvals, briefs, and reports. The frontend reduces complexity by organizing views around the user's next decision rather than exposing every backend operation at once.
