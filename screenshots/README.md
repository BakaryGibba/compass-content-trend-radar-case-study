## Capture Tips

- Browser width: 1440px or 1600px for portfolio screenshots.
- Prefer light mode unless dark mode is visually stronger and complete.
- Keep the left navigation visible when it helps reviewers understand the product.
- Crop browser chrome only if the screenshot still feels credible.
- Save final images directly in this folder with the filenames above.
