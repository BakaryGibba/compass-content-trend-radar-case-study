# Appendix

## Glossary

| Term | Meaning |
| --- | --- |
| Client profile | Structured context about the client, market, audience, brand tone, and risk boundaries |
| Seed keyword | Starting search phrase used to collect trends and expand topic research |
| Keyword intent | Classification of what a searcher likely wants and where they are in the buying journey |
| Content pillar | Durable strategic theme that groups related ideas |
| Production brief | Creator-facing guidance for turning an idea into content |
| Source status | Health and warning metadata for an external collector |

## Privacy Notes

Do not publish:

- `.env` files or API keys;
- raw trend exports;
- logs or provider errors containing private details;
- private client profiles;
- scraped pages or screenshots with private account data;
- proprietary source code dumps.
