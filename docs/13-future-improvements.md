# Future Improvements

## Production Roadmap

| Area | Improvement |
| --- | --- |
| Persistence | Replace local files with PostgreSQL and object storage |
| Jobs | Add queue-backed background strategy runs with retry and cancellation |
| Auth | Add authentication, roles, and client/team access boundaries |
| Observability | Add structured logs, metrics, run traces, and source failure dashboards |
| Evaluation | Track idea quality, approval rate, publishing outcomes, and content performance |
| Reports | Add versioned report snapshots and export templates |
| AI governance | Add prompt/version tracking, model evaluation, and confidence annotations |
| Integrations | Connect to official SEO, social, and content-planning tools where available |

## Product Roadmap

- richer client memory and brand-learning history;
- stronger content calendar views;
- approval comments and revision loops;
- creator handoff packs;
- export to Google Docs, Sheets, Notion, or project-management tools;
- multilingual market research;
- comparative competitor content overlays.

## Strategic Direction

Compass can evolve from a trend radar into a full content operations assistant: one that recommends what to create, explains why, tracks what was approved, and learns from what performed.
